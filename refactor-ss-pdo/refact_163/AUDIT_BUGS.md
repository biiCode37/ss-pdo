# AUDIT BUGS — Refactor 163: Natural Alphanumeric Route Sorting

## Daftar Temuan Masalah & Ketidaksesuaian

| ID Temuan | Lokasi Kode | Keparahan | Deskripsi Singkat | Dampak User | Mitigasi |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **BUG-163-01** | `src/services/routes/routes.ts`, `src/services/dailyRouteReportService.ts` | **Medium** | Pengambilan master rute di database Supabase menggunakan `.order('route_code', { ascending: true })` berbasis ASCII text comparison murni. String `"JAK.115"` diurutkan sebelum `"JAK.15"` karena karakter `"1"` < `"5"`. | Pengguna melihat urutan rute acak/tidak wajar di form selector, monitoring wilayah, dan dropdown (`JAK.01, JAK.112, JAK.115, JAK.15, JAK.29`), menyulitkan pencarian rute secara cepat. | Buat utilitas terpusat `compareRouteCodes` dan `sortRoutesByCode` dengan opsi Intl Collator `{ numeric: true, sensitivity: 'base' }` dan normalisasi spasi/titik. Sort master list rute sebelum disimpan ke cache / dikembalikan ke pemanggil. |
| **BUG-163-02** | `src/components/monitoring/tabs/MonitoringFleetStatusTab.tsx` | **Low** | Pemetaan `routeMap.entries()` pada tab Status Armada tidak diurutkan, sehingga urutan rute bus non-SGO mengikuti urutan kemunculan data di database (`relevantShifts`). | Rute-rute yang memiliki armada kendala/non-SGO muncul acak-acakan di tampilan tab Armada, tidak terurut sesuai abjad/nomor rute. | Terapkan `sortRoutesByCode(list)` pada hasil konversi `routeMap.entries()`. |
| **BUG-163-03** | `src/components/monitoring/tabs/MonitoringKorwilTab.tsx` & `src/services/allRouteMonitoringService.ts` | **Medium** | Pada agregasi ringkasan pengawas korwil (`calculateSupervisorSummaries`), `teamRoutes` diambil via `.filter()` tanpa pengurutan natural eksplisit. | Daftar rute Mikrotrans di dalam accordion pengawas Korwil (Ranto, Abdul Manan, Moamar) tidak terurut secara natural saat di-expand. | Bungkus `routes.filter(...)` dengan `sortRoutesByCode(...)` di `calculateSupervisorSummaries` dan pastikan `sortRoutesByCode(team.routes)` di komponen accordion. |
| **BUG-163-04** | `src/components/monitoring/tabs/MonitoringRoutesTab.tsx` | **Low** | State `filteredRoutes` langsung mengembalikan hasil array `.filter()` tanpa jaminan pengurutan ulang. | Bila ada rute baru dimasukkan atau saat filter diterapkan, urutan kartu rute berisiko tidak stabil. | Kembalikan `sortRoutesByCode(list)` pada `useMemo` `filteredRoutes`. |
| **BUG-163-05** | `src/components/monitoring/tabs/MonitoringWaReportTab.tsx` & `src/components/waReport/useWaReportData.ts` | **Medium** | Generator laporan teks WhatsApp Format 1, Format 2, dan Format 3 memetakan rute langsung dari urutan `data.routes`. Daftar rute belum lengkap (`unconfirmedRoutes` / `pendingRoutes`) juga belum diurutkan secara natural. | Pada pesan broadcast WhatsApp yang di-generate, nomor urut rute (`1. JAK 115`, `2. JAK 15`) tidak berurutan sesuai kaidah penomoran operasional. Chip rute yang belum selesai juga tidak berurutan. | Terapkan `sortRoutesByCode` pada `sortedRoutes` di tab WA Report dan `filteredRoutes` serta `unconfirmedRoutes` di `useWaReportData.ts`. |
| **BUG-163-06** | `src/components/routeSelector/useBulkRouteForm.ts` | **Low** | Hasil inspeksi rute massal `inspectBulkRoutesWithConcurrency` langsung disimpan ke state `bulkItems` sesuai respons jaringan. | Daftar review rute massal sebelum disimpan ke database tampil acak. | Terapkan `sortRoutesByCode(results)` sebelum memanggil `setBulkItems`. |
| **BUG-163-07** | `src/utils/routeSorting.ts` | **Medium** | Karakter spasi (`' '`, ASCII 32) memiliki kode ASCII lebih kecil dari titik (`'.'`, ASCII 46). Tanpa normalisasi, `"JAK 05"` akan muncul sebelum `"JAK.01"`. | Ketidakkonsistenan penulisan rute dari pengguna atau spreadsheet (misal `JAK 05` vs `JAK.01`) menyebabkan rute terpisah kelompok. | Tambahkan `normalizeRouteCodeForSort` yang mengubah spasi dan underscore menjadi titik (`.`) sebelum perbandingan Intl Collator. |
